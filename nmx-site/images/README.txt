Put your real photos in this folder, named to match what's referenced in
portfolios-data.js — for example:

  images/rem-1.jpg
  images/rem-2.jpg
  images/zenna-1.jpg

Until a file exists at that path, the site shows a labelled placeholder
tile instead, so nothing breaks — just add photos here whenever they're
ready and refresh the page.

For a new creator, use whatever filenames you like as long as they match
the "gallery" array you add for them in portfolios-data.js.
